Конфигуратор расчёта по объекту Минтруд

Логика формы собрана по связке «получение данных → зонирование объекта → выдача сметы». Модули, зоны, оборудование, монтаж, расходные материалы и модель маржи объединены в единый расчёт.

1. Исходные данные проекта

Карточка проекта и финансовые параметры, которые влияют на итоговый расчёт: тираж центров, курсы валют, НДС и состав цифрового слоя.

2. Структура объекта и зоны

Зоны предзаполнены по схеме зонирования. Можно отключать помещения, уточнять площади и менять функциональную группу без потери связей с модульным расчётом.

Активно Зона Группа Площадь, м² Привязанных модулей

3. Конфигурация модулей

Каждый модуль связан с зоной, шаблоном спецификации и, при наличии, с контентным или цифровым слоем. Количество можно менять: пакет сам масштабирует оборудование, монтаж и маржинальность.

4. Расчёт по модулям

Сводная таблица по каждому активному модулю: сервисный слой, закупка оборудования, продажа, монтаж, расходники, маржа оборудования и итог с НДС.

Модуль Зона Ед. Сервисы, без НДС Закупка обор. Продажа обор. Маржа обор. Итого, с НДС

Контроль и предупреждения

Проверки привязки к зонам, базовой вместимости и состава активных модулей.

Профили маржи оборудования

Свод по применённым профилям из спецификации: скидка дилера и соответствующая продажная наценка.

5. Детальная спецификация

Сформирована из шаблонов выдачи: оборудование, монтаж / ПНР и расходные материалы. Сервисные бюджеты вынесены в расчёт по модулям, чтобы не смешивать контент с закупкой оборудования.

Состояние сохраняется локально в браузере. Пересчёт выполняется без внешних зависимостей; курсы валют и НДС можно менять в исходных данных.
